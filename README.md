# ollama

[![License](https://img.shields.io/github/license/craftslab/ollama.svg)](https://github.com/craftslab/ollama/blob/main/LICENSE)



## Introduction

*ollama* is the ollama extensions of [ai-flowx](https://github.com/ai-flowx) written in Go.



## Index

- [archive](archive/README.md): Archive and restore local Ollama models for offline transfer.
- [export](export/README.md): Export Ollama model data with the Go-based CLI.
- [serve](serve/README.md): Serve Ollama functionality with the Go-based module.
